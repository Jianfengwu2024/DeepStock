# 两支流 FK 策略说明与真实测试报告

更新时间：2026-08-25

## 一句话说明

这个策略不再研究边界层，也不再挑选 Top-K 强股。它每月把板块股票固定分成两条支流，分别计算下一日漂移和有效势；预测多时买入该支流全部股票，预测平时保持原仓，预测空时清仓，全部持股统一等权。

## 已删除的旧逻辑

- 边界厚度、厚度斜率、黏性、湍流和脱节。
- 市值加权自制指数作为策略收益。
- 五级消融和五道看涨门。
- SourceProximityRanker、Top-K 和个股强弱排序。
- 3条或4条可配置支流。

旧文件可能仍作为历史研究代码存在，但训练、推断、回测和页面入口都不再调用这些逻辑。

## 两支流怎样形成

1. 只使用月初以前60个完整交易日的一分钟数据。
2. 根据个股分钟价格速度的同步相似度做层次聚类。
3. 固定切成两组，并冻结到月底，月内绝不重排。
4. 二分受到最小规模约束。半导体板块默认每组至少达到全板块股票数的10%，不能再把一个离群股单独当成支流。
5. 没有足够分钟线的股票不参与当月分组；不能形成两个有效组时，该月不交易。

## 每条支流的输入

每条支流先用当日有效成员等权合成日收益，只保留5个简单状态：

- 当日收益。
- 最近5日平均收益。
- 最近20日平均收益。
- 最近20日波动率。
- 当日支流内部同步一致性。

不要求每个成员每天都有完整分钟线。有效成员覆盖率达到80%即可计算支流状态；停牌或缺线的持仓股票当日收益按0处理。这样不会因为一只股票停牌让整个支流当天失效。

## 贝叶斯 FK

两条支流完全独立拟合：

- 漂移：贝叶斯岭回归，4个输入，没有隐藏层；越近的样本权重越高，默认半衰期60个交易日。
- 扩散：只有一个残差方差常数，不让随机噪声增加参数自由度。
- 有效势：3个输入，估计当前漂移方向继续存活的可信度。

旧算法把漂移再次乘以存活概率，然后拿已经缩小的均值去和真实收益波动阈值比较。这在数学上重复收缩，条件均值也天然小于单日实现波动，所以长期全部判平。

新算法把三个量分开：

```text
漂移均值             决定方向
漂移方向后验概率     判断方向是否明确
有效势存活概率       判断这个方向是否值得相信
漂移 / 预测标准差    判断信号是否大于噪声
```

默认门槛为：方向后验概率不低于60%，漂移信噪比不低于0.10，势存活概率不低于35%。收益的 `0.35 × 20日波动率` 平区间只用于评估真实涨跌分类，不再控制交易方向。

有效势的训练标签也已修正。旧算法判断下一日是否延续5日均线，但交易方向来自漂移模型，两者可能相反。新算法在训练期内部逐日做因果滚动漂移预测，再判断该历史漂移方向是否在下一日存活。当前样本的目标值不会参与自身漂移预测。

交易方向为：

```text
方向、信噪比、势可信度全部过门，漂移为正 => 多
方向、信噪比、势可信度全部过门，漂移为负 => 空
其余                                      => 平
```

旧算法保留为严格消融：它使用独立的等权漂移后验、旧动量延续势和旧衰减判定，不与新算法共享拟合结果。

## 持仓状态机

- 多：该支流未持有时，买入全部有效成分股。
- 平：已经持有则继续持有；尚未持有则不建仓。
- 空：清空该支流全部股票。
- 两条支流都持有时，对所有股票统一等权，不给某条支流额外权重。
- 回测收益来自实际持仓股票下一交易日收益，不再用板块指数替代。

## 因果约束

- 月度分组只读月初以前的数据。
- 模型训练标签的 `target_time` 必须早于或等于训练截止时间。
- 当日信号只在下一可交易时点生效。
- 样本外测试月份严格受用户选择的开始和结束日期限制；训练仍可使用开始日期以前的历史。

## 145六个月真实消融

数据：`/home/share/data/sectors/semiconductor.duckdb`

- 板块：半导体。
- 数据股票：96只。
- 样本外月份：2024-05至2024-10，连续6个月。
- 成熟训练样本：两条支流最少182日。
- FK路径：10000。
- 交易成本：10 BP。
- 有效样本外交易日：120日，共240个支流方向判断。

严格消融结果：

| 方法 | 空 / 平 / 多 | Balanced Accuracy | Macro F1 | 开仓率 | 成本后收益 | 最大回撤 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 近期后验信号 | 9 / 229 / 2 | 31.75% | 17.18% | 24.17% | 6.43% | 11.55% |
| 旧衰减漂移 | 0 / 240 / 0 | 33.33% | 16.82% | 0.00% | 0.00% | 0.00% |

新方法修复了“条件均值永远越不过真实收益阈值”的全平问题，但没有超过旧模型的均衡命中率。6.43%的收益来自极少数开仓和持仓阶段，不能证明预测有效。

这个结果说明：

1. 判定量纲错误已经修复，模型不再因为阈值设计而机械地全部判平。
2. 有效势已经与漂移方向对齐，不再用无关的5日动量方向给漂移做门控。
3. 新旧消融现在使用独立后验，比较过程是严格的。
4. 当前漂移方向命中只有47.08%，漂移与下一日收益的秩相关为 `-0.115`。真正的瓶颈是漂移输入没有预测力，不是门槛。
5. 当前不能宣称策略具有稳定交易价值，也不能根据这6个月收益反向调整门槛。

## 下一步应怎样测

不要继续调低门槛。下一轮应该改进漂移的物理输入，而不是让同一批弱信号更容易交易。当前4个日频输入本质上仍是收益均线和同步度，没有真正把支流日内路径的收盘段流向、路径效率和局部阻力写入漂移生成元。新增输入必须先在训练期内做消融，再用新的连续样本外区间验证，不能继续使用本报告的6个月挑参数。
