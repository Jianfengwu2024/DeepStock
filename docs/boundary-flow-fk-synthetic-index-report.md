# 两支流 FK 策略说明与真实测试报告

更新时间：2026-08-25

## 一句话说明

这个策略不再研究边界层，也不再挑选 Top-K 强股。它每月把板块股票固定分成两条支流，分别计算下一日漂移和有效势；预测多时买入该支流全部股票，预测平时保持原仓，预测空时清仓，全部持股统一等权。

## 已删除的旧逻辑

- 边界厚度、厚度斜率、黏性、湍流和脱节。
- 市值加权自制指数作为策略收益。
- 五级消融和五道看涨门。
- SourceProximityRanker、Top-K 和个股强弱排序。
- 3条或4条可配置支流。

旧文件可能仍作为历史研究代码存在，但训练、推断、回测和页面入口都不再调用这些逻辑。

## 两支流怎样形成

1. 只使用月初以前60个完整交易日的一分钟数据。
2. 根据个股分钟价格速度的同步相似度做层次聚类。
3. 固定切成两组，并冻结到月底，月内绝不重排。
4. 二分受到最小规模约束。半导体板块默认每组至少达到全板块股票数的10%，不能再把一个离群股单独当成支流。
5. 没有足够分钟线的股票不参与当月分组；不能形成两个有效组时，该月不交易。

## 每条支流的输入

每条支流先用当日有效成员等权合成日收益，只保留5个简单状态：

- 当日收益。
- 最近5日平均收益。
- 最近20日平均收益。
- 最近20日波动率。
- 当日支流内部同步一致性。

不要求每个成员每天都有完整分钟线。有效成员覆盖率达到80%即可计算支流状态；停牌或缺线的持仓股票当日收益按0处理。这样不会因为一只股票停牌让整个支流当天失效。

## 贝叶斯 FK

两条支流完全独立拟合：

- 漂移：贝叶斯岭回归，4个输入，没有隐藏层。
- 扩散：只有一个残差方差常数，不让随机噪声增加参数自由度。
- 有效势：3个输入，估计当前漂移继续存在的阻力。

FK中的有效漂移为：

```text
有效漂移 = 原始漂移 × exp(-有效势)
```

Monte Carlo仍输出下一日空、平、多概率和不确定性，但交易方向不再取三个概率中略大的那个。最终方向严格由有效漂移决定：

```text
有效漂移 > 平稳阈值      => 多
有效漂移 < -平稳阈值     => 空
其余                       => 平
```

这样可以避免 `34% / 29% / 36%` 这种接近随机的概率被强行解释成看多。

## 持仓状态机

- 多：该支流未持有时，买入全部有效成分股。
- 平：已经持有则继续持有；尚未持有则不建仓。
- 空：清空该支流全部股票。
- 两条支流都持有时，对所有股票统一等权，不给某条支流额外权重。
- 回测收益来自实际持仓股票下一交易日收益，不再用板块指数替代。

## 因果约束

- 月度分组只读月初以前的数据。
- 模型训练标签的 `target_time` 必须早于或等于训练截止时间。
- 当日信号只在下一可交易时点生效。
- 样本外测试月份严格受用户选择的开始和结束日期限制；训练仍可使用开始日期以前的历史。

## 145真实测试

数据：`/home/share/data/sectors/semiconductor.duckdb`

- 板块：半导体。
- 数据股票：96只。
- 样本外月份：2024-05。
- 成熟训练样本：两条支流最少182日。
- FK路径：1000。
- 交易成本：10 BP。
- 有效样本外交易日：18日。
- 当月支流规模：10只和69只，其余股票因60日分钟线完整度不足未进入当月分组。

分类结果：

| 指标 | 结果 |
| --- | ---: |
| Balanced Accuracy | 31.28% |
| Macro F1 | 24.40% |
| Brier | 0.6857 |
| Log Loss | 1.1318 |
| ECE | 0.0966 |

默认 `0.35 × 20日波动率` 平稳阈值下，两条支流18日全部判平，因此没有开仓，收益和回撤均为0。

这个结果说明：

1. 数据链已经完整运行，两支流分组、独立后验、真实持仓收益和页面制品都能生成。
2. 受约束聚类修掉了此前 `59:1` 的假支流。
3. 成员覆盖率修复把同月有效预测从4日提高到18日。
4. 分类能力仍接近随机，当前不能宣称具有交易价值。
5. 不开仓是有效漂移没有超过默认阈值，不是策略代码没有执行。

## 下一步应怎样测

不要为了让策略开仓而偷偷调低阈值。下一轮应在页面上明确比较多个预先设定的平稳阈值，并使用更多连续样本外月份，观察有效漂移、开仓率和成本后收益是否稳定。阈值必须在测试前确定，不能根据样本外收益反向挑选。
