# 双流 FK 贝叶斯漂移基准报告

## 为什么要改

旧模型把漂移回归的截距强制固定为零。这等于假设：当路径效率和成分股同步率都为零时，板块下一日上涨与下跌的概率必然各为 50%。

真实结果不符合这个假设。旧基线中，半导体和人工智能的高置信看多信号有正收益，但看空信号后的平均收益仍然为正。模型的两个方向被强制做成镜像，导致它无法表达板块在某段历史中的基础上涨或基础下跌倾向。

## 怎么改

新的方向模型为：

`上涨对数胜算 = 贝叶斯基础漂移 + 路径效率系数 + 成分股同步率系数`

基础漂移与原有两个系数一起，只使用训练截止日前已经实现的收益进行拟合。它使用相同的 60 日半衰期近期加权和有限高斯先验；样本不足或涨跌接近平衡时，先验会把基础漂移压回零。因果外势校准也改用同一种带基础漂移的模型，避免训练和推理定义不一致。

以下内容没有变化：

- 方向概率门槛 `0.60`
- 信噪比门槛 `0.10`
- 存活率门槛 `0.35`
- 60 日拓扑
- `beta0 + C1` 外势
- 最强三分之一选股
- 5BP 交易成本
- 原仓位、涨停买不进和跌停卖不出规则

## 直白结论

贝叶斯基础漂移解决了模型逻辑上的错误对称假设，但它不是三个板块都有效的万能信号。

半导体的漂移方向正确率提高 1.23 个百分点，净收益增加 31.49 个百分点；最大回撤增加 8.58 个百分点，但收益回撤比仍由约 2.33 提高到约 2.95。这个板块支持保留贝叶斯漂移基准。

人工智能只多获得 1.40 个百分点收益，最大回撤却增加 5.09 个百分点，收益回撤比明显下降。新能源的方向正确率退化到接近随机，收益和回撤同时恶化。这两个板块不支持直接推广。

基础漂移使信号覆盖率和平均仓位明显提高。它带来的收益不能简单归因于预测变准，也包含更多市场暴露。因此后续不应继续降低方向门槛，而应判断一个板块当前是否存在稳定、可迁移的基础漂移；没有证据时应把该项收缩回零。
