高对流并没有对应更低的收益或更高的反转率。偏强和极强档反而有更高的平均收益与延续率，所以按对流强度减仓恰好删掉了一部分有效交易。

## 根本原因

设与支流方向同向的绝对流量为 `P`，反向绝对流量为 `N`。本次指标为：

\[
C=\frac{N}{P+N}
\]

而成员级方向效率可以写成：

\[
E=\frac{P-N}{P+N}
\]

因此：

\[
C=\frac{1-E}{2}
\]

两者在代数上就是互相转换的。当前路径效率先做分钟横截面平均，所以与成员级方向效率不完全相同，但真实样本中仍然产生了 `-0.9903` 的 Rank 相关系数。这说明简单反向流量占比几乎没有增加新信息，只是把已知漂移强度换了一个名字。

## 下一步判断

如果继续研究 FK 势能，对流量必须脱离这个一维恒等关系。下一版至少要包含路径效率无法推出的信息，例如：

- 同样反向流量下，冲突集中在少数分钟还是持续整日。
- 反向流量集中在少数股票还是整个支流同步发生。
- 局部冲突出现后，是被主漂移吸收，还是继续扩散到更多成员。

在这些量完成独立性检验前，不再把“反向流量占比”用于减仓。
