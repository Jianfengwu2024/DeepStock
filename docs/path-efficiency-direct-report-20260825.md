# 路径效率直接交易实验报告

## 结论

这次实验实现并验证了最简单的路径效率策略：路径效率为正就买入对应支流至 50%，为负就清仓，等于零则保持原仓位。两条支流独立判断，总仓位为 0%、50% 或 100%。策略不使用 FK、贝叶斯回归、有效势、概率门槛或连续看平状态。

真实样本外结果不支持把路径效率的正负号直接当作下一日涨跌方向。该方法可以保留为最小消融基准，但不应作为正式交易策略。

## 实验口径

- 任务：`PathEfficiency-001`
- 对照任务：`TwoBranchFK-004`
- 数据集：半导体板块，96 只具备分钟线的股票
- 区间：2024-01-01 至 2026-08-05
- 支流构造：60 日同步关系聚类，每月冻结一次
- 样本外交易日：591
- 交易成本：10 BP
- 信号执行：当天收盘后生成，下一交易日生效

## 结果

| 指标 | 路径效率直接交易 | 始终满仓两支流 | TwoBranchFK-004 |
| --- | ---: | ---: | ---: |
| 毛收益 | 18.28% | 64.11% | 9.42% |
| 净收益 | -12.17% | 61.35% | 4.59% |
| 最大回撤 | 35.91% | 32.13% | 8.02% |
| 平均仓位 | 54.15% | 100.00% | 7.78% |
| 开仓率 | 62.27% | 100.00% | 18.78% |
| 平均换手 | 50.35% | 2.84% | 7.65% |

路径效率直接信号的秩相关为 -0.0216，方向命中率为 50.17%，没有表现出稳定的下一日预测能力。正路径效率后的次日平均收益为 0.0712%，负路径效率后的次日平均收益反而更高，为 0.1566%。这与“正值看多、负值看空”的规则相矛盾。

## 为什么亏损

第一，路径效率描述的是当天价格路径的方向一致性，不等于下一日收益方向。它更像对已经发生趋势的测量，直接取符号会把当日方向误当成下一日预测。

第二，符号在零点附近频繁翻转，导致平均每日换手达到 50.35%。策略毛收益为正，但 10 BP 成本累计后净收益转负。

第三，半导体板块在测试区间整体上涨。直接策略频繁空仓，既没有获得择时优势，又损失了板块的长期上涨收益，因此远远落后于始终满仓基准。

TwoBranchFK 的净收益虽然只有 4.59%，但平均仓位仅 7.78%，最大回撤为 8.02%。它的主要作用不是提高绝对收益，而是通过后验和有效势大幅减少交易与风险暴露。

## 工程验证

- UI 中新增独立的“路径效率”策略，自动命名为 `PathEfficiency-001`。
- 配置页只显示 60 日支流历史和交易成本，内部设备固定为 CPU。
- 输出 `path-efficiency-predictions.json`、`path-efficiency-evaluation.json` 和 `path-efficiency-report.md`。
- 591 条预测均满足 `signal_time < available_at < target_time`，没有发现未来数据泄漏。
- 每条预测都保存 `training_cutoff` 和 `model_version=PathEfficiency-v1`。

## 建议

保留该策略作为所有复杂方法必须超过的最低对照，不再给它增加参数。下一步若继续研究路径效率，重点应放在它与下一日收益之间的条件关系，以及降低零点附近翻转造成的换手；不能因为本次毛收益为正，就把路径效率符号解释为可交易方向。
