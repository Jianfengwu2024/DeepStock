# 路径效率 FK 基线

## 唯一模型

每月用过去 60 个交易日的分钟线同步关系，把板块股票固定分成两条支流。每条支流每天只生成一个带方向的路径效率：

`路径效率 = 当日净位移 / 当日路径总长度`

贝叶斯模型只使用 `signed_path_efficiency` 估计下一交易日漂移，不再使用旧四项漂移、尾流或冲击恢复。Feynman-Kac 根据漂移、扩散和有效势给出每条支流的多、平、空后验。

## 唯一仓位规则

- 两支流都没有看空时，看多的支流恢复其 50% 满额仓位。
- 看平每次减去该支流 12.5 个百分点，即总满仓的四分之一。
- 双支流同时持续看平时，总仓位依次为 100%、75%、50%、25%、0%。
- 任一支流看空，全部股票立即清仓，包括另一支流的股票。
- 清仓后，看平不会重新开仓；只有新的看多信号可以开仓。

## 因果约束

支流划分每月固定，训练标签必须在训练截止时已经成熟。信号在下一可交易时点生效，回测计入换手和交易成本。
