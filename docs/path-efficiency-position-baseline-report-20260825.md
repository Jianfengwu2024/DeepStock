# 纯路径效率固定仓位基底实验

## 本次改动

TwoBranchFK 现在只使用 `signed_path_efficiency` 估计漂移，不再训练或展示其他漂移输入。

两条支流各自占总资金最多 50%，方向直接映射为固定目标仓位：

- 看多：该支流占总资金 50%。
- 看平：该支流占总资金 25%。
- 看空：该支流清仓。

看平不会连续减半。两条支流的总仓位只会是 0%、25%、50%、75% 或 100%。

## 实验设置

- 新任务：`TwoBranchFK-003`
- 任务 ID：`20260825-051744-TwoBranchFK-003-eef541`
- 数据：半导体板块 96 只股票
- 日期：2024-01-01 至 2026-08-05
- 样本外交易日：591
- 最少训练日：120
- FK 路径：10,000
- 漂移半衰期：60 日
- 交易成本：10 BP
- 验证：全部月度 walk-forward 折

除仓位规则外，实验参数与上一版纯路径效率结果一致。

## 直白结论

代码和仓位规则都按设计工作，但这次规则调整没有改善回测结果。

模型的方向预测完全没有变化，因为输入和模型仍是同一个纯路径效率。变化只来自仓位：两条支流在 1,182 个方向判断中有 1,095 次判平，因此固定半仓规则让策略在 511 个交易日维持 50% 总仓位，开仓率接近 100%。这已经很接近长期半仓持有整个板块。

换手上升主要发生在支流方向变化和月度成分重排时。固定半仓覆盖的股票更多，月度支流重排会改变更多个股权重，所以平均换手从 1.50% 升到 6.27%。

这说明固定仓位规则适合作为清晰、可解释的策略基底，但目前不能称为收益优化。真正需要继续优化的是“平”的判定质量和占比，而不是再混入更多漂移信号。
