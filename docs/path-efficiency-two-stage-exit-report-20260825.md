# TwoBranchFK 两级退场测试报告

## 改了什么

两条支流分别维护自己的持仓状态：

- 看多：该支流持有总资金的 50%，并清除看平计数。
- 第一次连续看平：该支流降到总资金的 25%。
- 第二次连续看平：该支流清仓。
- 看空：该支流立即清仓。
- 空仓后继续看平：保持空仓；再次看多才重新开到 50%。

模型、样本、随机种子和交易成本都没有改变。本次只比较仓位退出规则。

## 实验口径

- 数据集：半导体板块，96 只股票
- 时间：2024-01-01 至 2026-08-05
- 样本外交易日：591
- 漂移输入：仅 `signed_path_efficiency`
- FK 路径：10,000
- 交易成本：10 BP
- 旧基准：`TwoBranchFK-003`
- 新实验：`TwoBranchFK-004`

## 结果

| 指标 | 003 固定半仓 | 004 两级退场 | 变化 |
| --- | ---: | ---: | ---: |
| 净收益 | 17.26% | 4.59% | -12.67 个百分点 |
| 毛收益 | 21.69% | 9.42% | -12.27 个百分点 |
| 最大回撤 | 22.70% | 8.02% | -14.69 个百分点 |
| 平均仓位 | 52.07% | 7.78% | -44.29 个百分点 |
| 有仓交易日 | 99.49% | 18.78% | -80.71 个百分点 |
| 平均换手 | 6.27% | 7.65% | +1.38 个百分点 |

预测模型没有变化，因此平衡准确率、Brier、Log Loss、漂移方向命中率等预测指标完全相同。变化只来自仓位状态机。

## 仓位分布

新规则的 591 个交易日中：

- 空仓：480 日
- 25%：43 日
- 50%：65 日
- 75%：1 日
- 100%：2 日

旧规则有 511 日保持 50% 总仓位，原因是大量看平信号会永久保留半仓。新规则在第二次连续看平时退出，因此不再把“没有方向”误当成长期持仓理由。

## 直白结论

规则实现正确，但它把策略从“长期半仓”改成了“只在明确看多后短暂持仓”。回撤明显降低，收益也明显降低，且交易成本占毛收益的比例上升。

这个结果说明当前模型绝大多数时间输出看平。两级退场解决了旧规则长期滞留半仓的问题，但不能解决看多信号过少的问题。下一步若要提高收益，应改进信号质量或看多门槛，而不是让看平状态重新承担开仓功能。
