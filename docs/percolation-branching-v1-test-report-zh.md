# 渗流分枝 v1 测试报告

## 一句话结论

`PercolationBranching` 已经完成代码、接口和 DeepStock Lab 页面接入，也用 145 服务器上的半导体真实分钟数据跑通了一折样本外测试。但这次只验证“能不能正确运行”，**不能证明策略有效**。本次 18 个样本外交易日全部判为“多空同时贯通”，没有开仓，下一步应进入人机协同评估。

## 策略现在做什么

1. 只读取板块成分股的 1 分钟价格和成交量。
2. 分别建立多头传播网络和空头传播网络，两张网络互不混用。
3. 股票间只允许滞后 1 至 3 分钟传播；同一分钟一起异动算外部冲击。
4. 用过去 60 个交易日建立月度固定骨架，当月不重排。
5. 预测下一日四种状态：看空贯通、无贯通、多空同时贯通、看多贯通。
6. 只有“看多贯通”概率最高且不低于 60% 时才开仓，买入净贯通概率最高的前三分之一股票。
7. 回测扣除 5 BP 成本，并处理涨停买不进、跌停卖不出。

## 测试中修复的问题

第一次真实测试暴露了一个模拟错误：同一天发生的多个外部激活被合并成了一个巨大传播簇。这样会把互不相关的外部冲击误判为一条贯通链，导致多头和空头巨型簇都接近 100%。

现在每个外部源的传播谱系独立模拟，只取其中最大的真实传播簇，不再把“多场雨”拼成“一条河”。对应回归测试已加入。修复后四相概率不再是固定的 0 或 1，18 天得到 18 组不同概率。

## 当前不能下的结论

- 不能说模型有预测优势。25% 均衡准确率就是四相随机基准水平。
- 不能评价收益能力，因为这折测试没有开仓。
- 不能据此调高或调低开仓门槛。当前主要问题是相态判断长期偏向“多空同时贯通”，不是交易门槛。
- 冒烟测试降低了置换次数和后验路径数，正式评估仍应使用 500 次置换和 10000 条后验路径。

## 人机协同评估重点

1. 查看 18 天的多空再生数 `R+ / R-`、实际四相和事件密度，判断“冲突相”是否确实符合盘面。
2. 检查半导体板块是否太大，内部存在多个同时但相反的子网络，导致冲突相成为常态。
3. 对比多数相、昨日延续、历史转移和简单再生数四条基线，确认复杂模型是否提供额外信息。
4. 在不调收益参数的前提下扩大样本外月份，先判断相态概率是否可校准，再谈交易规则。
