# SectorFlowBayes 设计规格

## 目标

SectorFlowBayes 只使用同一概念板块全部股票的同步一分钟价格和成交量，估计板块共同水势及其在个股之间的传播顺序。第一版服务于半导体板块，回答三个问题：

1. 当前板块是否形成方向一致、成交活跃度支持的共同运动；
2. 哪些股票领先板块，哪些股票最快响应板块；
3. 哪些股票沿共同方向持续前进，而不是在原地反复波动。

模型不预测固定的多空类别，不接入政策、新闻、财务数据，也不使用成交量速度、二维图像、Transformer或深度神经网络。

## 核心原则

- 不做时间聚合。一分钟结构和传播先后顺序必须完整保留。
- 降噪来自同一分钟的板块横截面，而不是单只股票的时间平均。
- 每只股票的板块水势都必须排除自身，避免循环归因。
- 价格速度不减去历史平均漂移，只除以此前数据估计的零中心鲁棒尺度。
- 成交量表示活跃度和观测置信度，不定义成交量速度。
- 所有在线输出在一分钟K线结束后形成，最早在下一分钟可用。
- 第一版优先可解释性和后验校准，不追求模型参数数量。

## 数据协议

### 同步面板

板块数据按A股连续交易分钟对齐：09:31至11:30、13:01至15:00，每个交易日240行。面板张量为：

```text
timestamp x symbol
```

每个单元包含收盘价、成交量和有效掩码。停牌、缺失、异常分钟不填充为零收益，而是保持无效；真实零价格变化必须保留。

### 因果归一化

对股票 `i`、交易分钟 `t`：

```text
raw_velocity[i,t] = log(close[i,t] / close[i,t-1])
velocity[i,t] = raw_velocity[i,t] / velocity_scale[i,slot(t)]
activity[i,t] = volume[i,t] / volume_baseline[i,slot(t)]
```

`velocity_scale`采用此前20个完整交易日相同盘中位置的一分钟收益零中心RMS，并设置最小尺度；`volume_baseline`采用此前20日相同分钟成交量中位数。两个基准在当前交易日开始前冻结，当日结束后才更新。

价格状态另外保存复权对数价格及其历史固定尺度，但板块共同水势的主要观测量是一分钟价格速度。任何当前横截面去均值都会删除共同趋势，因此禁止使用。

## 板块动态因子

### 状态

一分钟板块隐状态为：

```text
h[t] = [direction, flow_strength, activity, breadth, coherence, dispersion]
```

- `direction`：板块共同标准化价格速度；
- `activity`：板块相对成交活跃度；
- `breadth`：有效股票中与共同方向一致的比例；
- `coherence`：共同因子解释的横截面方差比例；
- `dispersion`：个股速度相对共同速度的离散程度；
- `flow_strength`：方向、活跃度和同步性的联合水势强度。

### 概率模型

采用低秩线性高斯动态因子，并用Student-t观测权重降低涨跌停、异常跳价和极端分钟的影响：

```text
factor[t] = persistence * factor[t-1] + process_noise[t]
velocity[i,t] = loading[i] * factor[t] + residual[i,t]
```

参数使用训练窗口中的数据估计；盘中使用因果滤波，不使用平滑器读取未来分钟。每个股票 `i` 的评分使用排除自身后重新计算的 `factor_without_i[t]`。第一版允许高效的解析留一法，不训练90个独立模型。

## 领先与响应归因

对每只股票分别拟合两个贝叶斯分布滞后回归：

```text
factor_without_i[t+k] <- velocity[i,t], activity[i,t]    # 领先
velocity[i,t+k] <- factor_without_i[t], activity[i,t]    # 响应
```

默认 `k=0..30` 分钟，回归系数使用层级收缩先验，使样本较少的股票回归板块总体分布。

输出包括：

- `leader_probability`：个股当前运动对未来板块同向水势具有正增量解释的后验概率；
- `leader_horizon_minutes`：后验质量最大的领先分钟；
- `response_probability`：当前板块水势对个股未来同向运动具有正解释的概率；
- `response_delay_minutes`：响应后验质量最大的延迟；
- `coupling_mean/std`：个股与板块水势耦合的后验；
- `residual_scale`：无法由板块解释的个股噪声。

## 不打转判定

在5、15、30、60分钟窗口计算因果路径效率：

```text
efficiency = abs(sum(raw_velocity)) / sum(abs(raw_velocity))
```

同时计算：

- 与板块方向一致的分钟比例；
- 同向运行长度的后验持续概率；
- 反向折返次数；
- 活跃度是否在运动出现时同步增加；
- 个股残差占总速度方差的比例。

不使用人工加权总分。源头接近度定义为一个联合后验事件：

```text
P(领先或快速响应，耦合强，路径效率高，残差低，成交活跃度确认 | 已知分钟数据)
```

UI必须同时展示其组成项，不能只展示一个不可解释的排名数字。

## Walk-forward验证

2024年作为初始训练期，2025年按月扩展训练窗口。每个测试月冻结归一化和模型参数，仅允许一分钟因果滤波更新隐状态。

主要评估：

- 板块水势对未来5、15、30、60分钟板块方向的概率校准；
- `leader_probability`对未来板块水势的增量Log Loss和Brier Skill；
- Top-K源头接近股票未来30、60、120分钟的板块相对收益；
- 排名Rank IC、Top-K减Bottom-K收益和换手后净收益；
- 领先延迟、响应延迟和耦合参数跨月稳定性；
- 后验覆盖率和残差自相关。

基线包括随机排名、单分钟动量、相对成交量、路径效率、静态板块Beta。任何结论必须以样本外增量指标为准。

## 工程边界

新增独立包 `src/bnhmm/sector_flow/`：

- `types.py`：面板、水势、归因和评估的不可变数据契约；
- `panel.py`：板块分钟数据读取、同步和掩码；
- `normalization.py`：按股票和分钟位置进行因果归一化；
- `factor.py`：鲁棒贝叶斯动态因子和leave-one-out滤波；
- `attribution.py`：领先、响应和层级收缩后验；
- `ranking.py`：路径效率及联合后验事件；
- `evaluation.py`：walk-forward预测和指标；
- `pipeline.py`：训练、推理、报告和产物编排。

现有策略、数据库、权重和报告保持不变。DeepStock Lab新增 `sector-flow-bayes` 策略，仍使用现有任务队列、显存监控、结果删除和板块数据集选择能力。

## UI结果

配置页只暴露模型真正需要的参数：训练起止日期、归一化回看日、最大传播延迟、动态因子过程噪声、Top-K和交易成本。

结果页新增：

- 板块一分钟水势曲线；
- 方向、活跃度、广度、同步性和不确定性摘要；
- 个股领先/响应排名表；
- 单只股票的传播后验和路径效率详情；
- walk-forward月度稳定性和Top-K样本外表现。

## 验收标准

1. 人工同步数据上能够恢复已知共同因子、领先股票和响应延迟；
2. 目标股票的leave-one-out水势不受其自身价格改变影响；
3. 归一化只读取此前完整交易日；
4. 一分钟信息不被聚合，信号最早下一分钟生效；
5. 半导体板块完成2024至2025 walk-forward并生成完整报告；
6. DeepStock Lab可以配置、启动、终止、查看和删除该模型实验；
7. 不以样本内拟合或单一命中率宣称模型有效。
