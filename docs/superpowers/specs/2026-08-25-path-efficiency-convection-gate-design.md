# PathEfficiencyFK 60 日对流门控设计

## 目标

在现有 `PathEfficiencyFK` 上增加一个简单的对流指标，用来判断漂移能否稳定传播。

- 基线固定为 60 日窗口。
- 路径效率和现有 FK 漂移继续决定多、平、空方向。
- 对流只能维持仓位、减仓或清仓，不能反向开仓，也不能把平或空改成多。
- 不增加神经网络、二阶数值微分或新的高维特征。

## 基线

基线模型命名为 `PathEfficiencyFK-60D-Baseline`，保持现有交易规则不变：

- 看多恢复该支流的目标仓位。
- 看平按现有规则逐次减仓。
- 任一支流看空，全部支流立即清仓。
- 清仓后，看平不能重新开仓，只有新的看多信号可以开仓。

## 对流指标

对每条支流、每个交易日，使用支流内所有成分股未经支流平均的分钟价格速度计算：

\[
C=
\frac{\sum_{t,i}|v_{i,t}|\,\mathbf{1}(v_{i,t}d<0)}
{\sum_{t,i}|v_{i,t}|+\epsilon}
\]

其中：

- `v(i,t)` 是股票 `i` 在分钟 `t` 的原始对数价格速度。
- `d` 是该支流当日带方向路径效率的符号。
- `C` 位于 `[0, 1]`，表示与支流主方向相反的微观流量占全部微观流量的比例。
- 当路径效率方向为零或有效分钟不足时，该日对流指标无效，不使用对流门控。

路径效率先在每分钟对成分股速度取平均，再计算整日净位移与总路程；对流指标则在平均之前计算成分股内部的反向流量。因此它不是路径效率的代数变形，能够观察被支流均值隐藏的内部对冲。

## 因果校准

每次 walk-forward 拟合时，只用训练截止日前已经成熟的对流指标建立经验分布。分别对两条支流独立计算训练期的：

- `q50`：中位数。
- `q75`：75% 分位数。
- `q90`：90% 分位数。

分位数在当前样本外预测点冻结，不允许用样本外数据更新。训练有效样本不足 30 行时，停用该支流的对流门控，保持基线仓位。

## 仓位门控

先由现有基线策略生成每条支流的目标仓位，再应用对流仓位上限：

| 当日对流强度 | 该支流仓位上限 |
| --- | ---: |
| `C <= q50` | 基线仓位，不额外限制 |
| `q50 < C <= q75` | 该支流满额仓位的 75% |
| `q75 < C <= q90` | 该支流满额仓位的 50% |
| `C > q90` | 该支流清仓 |

最终仓位取“基线目标仓位”和“对流仓位上限”中的较小值。

- 对流门控只处理当前支流；一条支流的极强对流不会单独清空另一条支流。
- 现有“任一支流看空则全部清仓”规则优先级最高，保持不变。
- 对流门控不能增加仓位，不能把零仓位恢复为非零仓位。

实验模型命名为 `PathEfficiencyFK-60D-ConvectionGate`。

## 数据与缓存

对流指标在 60 日支流数据构造阶段一次性生成并写入缓存，后续 walk-forward 和策略回测直接读取，不重复扫描分钟线。

缓存至少保存：

- 每日、每支流的对流强度。
- 指标有效性。
- 有效股票分钟数和总微观流量，用于质量检查。
- 数据构造版本，防止旧缓存被误读。

## 样本外比较

只比较两个模型，不继续加入其他多信号版本：

1. `PathEfficiencyFK-60D-Baseline`
2. `PathEfficiencyFK-60D-ConvectionGate`

二者必须使用相同的数据区间、训练截止时间、交易成本、支流划分、随机种子和 FK 参数。

报告包含：

- 成本后收益、最大回撤、平均仓位、平均换手。
- 漂移方向正确率、平衡正确率、漂移 Rank IC。
- 按对流强度四档统计下一日收益、趋势延续率和反转率。
- 对流指标与路径效率的相关性，确认它没有退化成路径效率的重复表达。
- 对流门控触发次数，以及每档减仓对收益和回撤的贡献。

## 验收标准

- 全流程严格 walk-forward，无未来数据参与分位数计算。
- 对流门控从未增加基线仓位，也从未生成反向仓位。
- 任一支流看空时仍然全部清仓。
- 60 日缓存只构造一次，两个模型共享同一份底层状态数据。
- 页面可以选择并运行两个模型，结果显示对流强度、门控档位和减仓原因。
- 自动化测试覆盖指标公式、分位数边界、无效数据回退、仓位单调性和全局看空清仓规则。
