# TwoBranchFK 路径效率漂移改造

## 目标

验证有符号路径效率能否独立提供下一交易日漂移信息。第一阶段不增加网络、隐状态或额外参数，避免旧动量输入稀释路径效率。

## 当前问题

旧漂移输入包含 1 日收益、5 日平均收益、20 日平均收益和日内一致性。前三项高度相关；日内一致性没有方向。现有“仅加路径效率”实际上仍包含旧四项，不能回答路径效率本身是否有效。

## 第一阶段：PathOnly

- 新增漂移特征集 `path_efficiency_only`，只包含 `signed_path_efficiency`。
- 保留现有旧四项、旧四项加路径效率、尾盘流向作为历史对照，不改变其计算含义。
- 正式策略暂不自动晋级。先在相同数据、月份、交易成本、FK 路径数、后验门槛下完成 walk-forward 消融。
- 波动率、绝对收益和低一致性继续只进入有效势，不进入 PathOnly 漂移。
- 报告明确区分“纯路径效率”和“旧四项 + 路径效率”，并展示漂移方向命中、漂移秩相关、均衡命中率、Macro F1、开仓率、净收益和最大回撤。

## 晋级条件

PathOnly 只有同时满足以下条件，才进入第二阶段：

1. 净收益优于旧四项和当前正式模型。
2. 最大回撤没有明显恶化。
3. 漂移秩相关不低于现有“旧四项 + 路径效率”。
4. 优势不能只来自显著更高的开仓率；报告必须并列展示开仓率和换手。

单折结果只作为候选证据，不能据此宣称稳定有效。

## 第二阶段：PathMagnitude

仅当 PathOnly 晋级后实施。增加归一化总路程 `L` 和交互项 `E * L`，用于区分小幅单调移动与大规模定向流动：

`drift = beta0 + beta1 * E + beta2 * L + beta3 * E * L`

第二阶段不恢复旧四项，不引入神经网络。

## 测试

- 单元测试锁定 PathOnly 只含一个漂移输入。
- 测试消融名称、报告标签和产物协议。
- 运行完整测试集。
- 在半导体板块执行与现有结果相同配置的 walk-forward 实验，并保存中文报告。
