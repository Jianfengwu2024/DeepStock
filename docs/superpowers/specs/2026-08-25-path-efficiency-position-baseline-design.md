# 纯路径效率仓位基底设计

## 目标

将 `signed_path_efficiency` 设为 TwoBranchFK 唯一正式漂移输入，并建立明确的多、平、空仓位规则。新任务不再训练、回测或展示旧四项、尾盘流向及其他多信号消融。

## 信号基底

- 正式漂移特征集固定为 `path_efficiency_only`。
- 每条支流仍独立执行 FK 漂移与有效势预测。
- 方向门槛、信噪比门槛、趋势存活概率和交易成本口径保持不变。
- 旧特征定义可以保留在底层代码中供历史结果解析，但不进入新任务计算。

## 仓位规则

两条支流各自拥有总资金的 50% 预算。每条支流的目标预算利用率固定为：

- 看多：100%，即占总资金 50%。
- 看平：50%，即占总资金 25%。
- 看空：0%，即清空该支流。

看平是固定目标仓位，不根据前一日仓位连续减半。因此两条支流组合后的总仓位只可能是 0%、25%、50%、75% 或 100%。支流内部继续对全部成分股平权配置，不对剩余支流重新归一化到满仓。

## 状态与数据

策略决策应直接保存每条支流的目标仓位比例，而不再只保存是否持有的布尔值。总仓位、个股目标权重、换手和交易成本均根据真实目标权重计算。

`open_position` 继续表示总仓位是否大于零，以兼容现有评估结构。预测制品增加或明确输出支流目标仓位，便于前端和报告解释半仓状态。

## 输出调整

- 新任务只输出纯路径效率策略的评估、预测、后验和中文报告。
- 页面移除“信号消融”对比表，不再展示其他输入方法。
- 报告说明固定仓位映射，并展示开仓率、平均总仓位、换手、净收益和最大回撤。
- 历史任务制品保持可访问，不迁移或删除既有文件。

## 验证

自动测试必须覆盖：

1. 单支流多、平、空分别映射为总资金 50%、25%、0%。
2. 多/平组合总仓位为 75%，平/平为 50%，空/空为 0%。
3. 连续看平始终保持 50% 总仓位，不发生递归减半。
4. 个股权重之和等于目标总仓位，换手按新旧真实权重之差计算。
5. 新任务只拟合 `signed_path_efficiency`，不生成多信号消融结果。
6. Web 页面只展示纯路径效率策略结果。

完成后运行完整测试，并在 145 上执行一次同口径半导体板块 walk-forward 验证。
