# 反向流量集中度设计

## 目标

把 `PathEfficiencyFK-60D-ConvectionGate` 的旧“反向流量占总流量比例”替换为股票与分钟联合平面上的反向流量集中度，避免指标与路径效率近似互为线性变换。

## 定义

对某支流某交易日，先用分钟截面的支流平均原始对数价格速度之和确定当日方向 `d`。每个有效的“股票 × 分钟”单元速度为 `v_i`，反向流为：

```text
w_i = abs(v_i),  when v_i * d < 0
w_i = 0,         otherwise
```

设全部有效单元数为 `n`，反向总流量为 `W = sum(w_i)`，反向流份额为 `p_i = w_i / W`。指标采用按样本数归一化的 HHI：

```text
C = (n * sum(p_i ** 2) - 1) / (n - 1)
```

`C` 截断到 `[0, 1]`。均匀分散于全部有效单元时接近 0，集中于一个单元时为 1。`W` 不进入指标值，只用于判断反向流是否存在。少于两个有效单元、支流无净方向、总流量为零或反向总流量为零时，集中度无效。

## 策略约束

- 60 日支流窗口、路径效率 FK、训练期 `q50/q75/q90` 因果分档保持不变。
- 集中度只能降低当前支流仓位上限或清仓，不能开仓、加仓或反向开仓。
- 任一支流被 FK 判断看空时，仍立即清空全部支流。
- 旧反向流量占比不保留兼容计算；缓存构造版本必须升级并强制重建。

## 诊断与验收

- 单元测试证明集中度区分“相同反向总量、不同空间时间分布”。
- 单元测试覆盖单点集中、均匀分散、无反向流和无支流方向。
- 报告继续显示与绝对路径效率的 Rank 相关性，并新增集中度分位档的收益、延续率和反转率。
- 在半导体 96 股真实数据上重建 60 日缓存并严格滚动样本外比较；只有收益/回撤或分档单调性提供证据时才考虑替换正式基线。
