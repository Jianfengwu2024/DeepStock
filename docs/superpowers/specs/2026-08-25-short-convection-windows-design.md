# 短期反向流量集中度窗口设计

## 边界

60 日只用于每月冻结两支流成员，不属于对流计算窗口。对流是短期量，预计算最近 `1/2/3/5` 个已完成交易日的四套反向流量集中度，策略默认使用 3 日。

## 构造

对每个信号日、每支流和每个窗口：

1. 使用信号日已经冻结的支流成员，跨月时也不切换成员。
2. 汇集窗口内所有有效“股票 × 分钟”速度单元。
3. 用同一窗口内的支流平均速度总和确定主方向。
4. 对逆主方向的绝对速度计算归一化 HHI 集中度。
5. 数据不足、无主方向或无反向流时记为无效。

四套数组随 60 日支流缓存一次写入。回测只选择一个已缓存窗口，不读取分钟线、不重新构造。

## 接口

- 数据契约增加固定窗口轴 `(1, 2, 3, 5)`。
- `ConvectionGate` 显式接收窗口，默认 3 日。
- CLI、Web 请求和配置页增加 `convection_lookback_sessions`，只允许 `1/2/3/5`。
- 预测、诊断和报告写出实际使用窗口，避免不同实验混淆。

## 验收

- 单元测试证明四套窗口同时存在，且 2/3/5 日只使用截至信号日的数据。
- 测试证明策略默认读取 3 日，切换窗口不会触发数据构造。
- 缓存版本再次升级，旧的单日集中度缓存必须失效。
- 145 只重建一次 60 日支流缓存，并从同一文件读取四套对流数据。
