# 60 日连续坐标 FK 与失败算法清理设计

## 目标

DeepStock Lab 只保留基础 BNHMM 与整板块 FK-贝叶斯。FK 数据不再按交易日重新归零，而是让每个信号日使用一个完整、因果的 60 交易日价格路径。

## 60 日价格坐标

对信号交易日 `t`，取最近 60 个完整交易日 `t-59 ... t`，每只股票使用窗口前一交易日 `t-60` 的最后有效收盘价作为固定锚点：

`x_i(tau) = log(P_i(tau) / Close_i(t-60))`

同一个窗口内的所有分钟共享同一个锚点。下一个信号日窗口整体前移一天，锚点也前移一天。任何锚点、缩放和特征都只能使用信号日及以前的数据。

板块连续坐标是当分钟有效成分股坐标的等权平均。至少 80% 成分股有效时该分钟才有效。窗口路径显式包含相邻交易日收盘到下一交易日首个价格之间的隔夜位移，不再只统计日内连续分钟。

## FK 状态

每个信号日从完整 60 日路径生成：

- `rolling_log_position_60d`：窗口末端相对锚点的板块对数位移。
- `rolling_path_efficiency_60d`：60 日净位移除以包含隔夜位移的总路径长度。
- `rolling_diffusion_60d`：去除平均漂移后的分钟增量二次变差。
- `rolling_drift_60d`：60 日板块位移除以有效路径步数。

下一交易日标签改为真实收盘到收盘收益，包含隔夜信息。现有一日反向流量外势、交易成本、涨跌停、峰值回撤止损和严格 walk-forward 保持不变。

FK 的默认方向模型继续保持低参数：方向特征使用 `rolling_log_position_60d` 与 `rolling_path_efficiency_60d`；显著波动层额外使用 `rolling_diffusion_60d`。不增加神经网络层数。
